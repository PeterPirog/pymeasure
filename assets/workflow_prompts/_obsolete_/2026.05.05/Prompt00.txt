============================================================
COMMAND FORM LEGEND
============================================================

Use only these values:

command only
query only
command/query
unknown
needs-verification

Definitions:

command only = write/action command exists, no query form is documented.
query only = query exists, no write/set form is documented.
command/query = both command and query forms are documented.
unknown = the guide mentions the command but the form cannot be determined.
needs-verification = OCR, conversion, or source inconsistency must be checked manually.
