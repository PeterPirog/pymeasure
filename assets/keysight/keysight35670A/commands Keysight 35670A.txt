Agilent/Keysight 35670A Dynamic Signal Analyzer — commands.txt
Generated for PyMeasure driver planning.

Source:
- Agilent 35670A Dynamic Signal Analyzer, GPIB Programming with the Agilent 35670A,
  Appendix A: Agilent 35670A Command Summary.
- The manual states that Appendix A contains all GPIB commands recognized by the Agilent 35670A
  and that all commands have a query form unless marked "command only" or "query only".

Legend:
- command only   = command has no query form.
- query only     = query has no command/set form.
- command/query  = command form exists; append "?" for query form.
- [1|2|3|4]      = command is indexed by trace/window/channel number.
- [:...]         = optional SCPI node.
- [SENSe:]       = SENSe prefix is optional according to the manual.

Counts:
- Canonical command reference entries extracted from TOC: 430
- Appendix A parsed table entries: 428

WARNING FOR CODEX:
Use this file as the command inventory only. Do not blindly implement every command as Instrument.control.
Command-only operations should become methods. Query-only operations should become Instrument.measurement
or read methods. Large-data/block-transfer commands need dedicated parsers.

Cross-Reference from Front-Panel Keys to GPIB Commands

Introduction

This section lists analyzer hardkeys and softkeys and their equivalent GPIB commands.

Softkeys are indented to indicate their position in the menu tree. Keys that do not have an equivalent
GPIB command are excluded from the list. Keys which appear in multiple menus may appear only once.
For example, time capture is available in most instrument modes and appears in multiple Measurement
Data hardkey menus. The GPIB command for time capture is only listed once.

Multiple GPIB commands may be required for a single softkey. In these cases, the entire command string
is listed. The command string includes valid parameter values.

You can also determine the equivalent GPIB command for any key sequence by turning on the GPIB
echo facility. With GPIB echo on, the analyzer displays the equivalent GPIB command for each front
panel key sequence. To turn on GPIB echo, press the following keys:
    [ Local/GPIB ]
       [ GPIB ECHO ON OFF ] to highlight ON.
